Deux contrôles indépendants sur chaque question

Une question n'est validée que si les deux contrôles sont d'accord. Cliquez sur une catégorie pour voir les questions concernées.

Exécution sur la base

La requête de l'agent et la requête de référence sont lancées sur la base. Les lignes renvoyées doivent être identiques.

Relecture par un juge LLM

Méthode LLM-as-a-judge : un autre modèle que celui de l'agent relit le SQL et le note de 1 à 5 sur cinq critères.

Bon résultat selon la difficulté
